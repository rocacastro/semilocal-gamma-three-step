# Semilocal convergence beyond exact majorization

**Supplementary material and reproducibility repository** for

**Semilocal convergence beyond exact majorization for an efficient three-step method under gamma conditions**

by Rodrigo Castro Marín, Lía Paz Guzmán Pinto, Luis Fernando Echeverri Delgado, Óscar Antonio Restrepo Gutiérrez, and Gerardo Andrés Honorato Gutiérrez.

This repository contains the complete Supplementary Material S1–S6, exact and symbolic verification programs, high-precision numerical experiment programs, and the generated data used in the supplementary tables.

The sufficient condition verified in this repository is

\[
0<\beta\gamma\leq \frac{1547}{10000}=0.1547.
\]

## Repository contents

- `supplementary_material_gamma.tex`, `supplementary_material_gamma.pdf` — complete Supplementary Material S1–S6.
- `code/` — exact, symbolic, audit, and numerical reproduction programs.
- `results/` — outputs generated by the included programs.
- `requirements.txt` — pinned Python packages used by the verification scripts.
- `build_supplement.py` — compiles the supplementary material as a standalone document.
- `REPRODUCIBILITY.md` — detailed reproduction instructions and interpretation of the outputs.
- `CITATION.cff` — citation metadata for GitHub.
- `.zenodo.json` — metadata prepared for a future Zenodo release.

## Quick start

Create an isolated Python environment and install the required packages:

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Run the exact/rational criterion and the quantitative comparison with Cordero et al. (2015):

```bash
python code/run_verifications.py --rational-only
```

Run all non-experimental verification programs:

```bash
python code/run_verifications.py
```

Reproduce the eleven high-precision experiments used in Supplementary Section S5:

```bash
python code/run_verifications.py --experiments
```

The experimental run uses 1000 decimal digits and five cycles and is considerably more expensive than the rational checks.

## Compile the Supplementary Material

A TeX distribution with `pdflatex` is required. Run:

```bash
python build_supplement.py
```

The Supplementary Material is self-contained and does not require external label or source files.

## Reproducibility scope

The exact criterion checks use rational arithmetic. The numerical examples use multiprecision floating-point arithmetic and are **not** interval computations. Residuals of discretized systems are not presented as rigorous quadrature-error bounds. The refinement differences are maxima on the stated 401-point grid, not certified sup-norm bounds on the continuous interval.

See `REPRODUCIBILITY.md` and the Supplementary Material for full details.
